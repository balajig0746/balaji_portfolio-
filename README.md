# Balaji's Personal Portfolio

A responsive portfolio website made with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the `index.html` file in a browser, or open the folder in VS Code.
3. Recommended: use the VS Code **Live Server** extension and click **Go Live**.

Search in `index.html` for:
- `balajig074@gmail.com` — replace with your actual email.
- `https://www.linkedin.com/in/balaji-gajji-91b8a5357?utm_source=share_via&utm_content=profile&utm_medium=member_android` — replace with your LinkedIn profile URL.
- Project descriptions and repository links — update to match your real work. The Weather Dashboard, To-Do List, Calculator, and Python Quiz are portfolio ideas/templates; implement them before presenting them as completed projects.
- Education spelling, percentages, and dates — verify these details.
- Add your resume PDF to this folder and add a download link if you want a CV button.

The contact form is intentionally not included; the email button opens the visitor's email application.
External Google Fonts need an internet connection; the site still works without them using fallback fonts.
